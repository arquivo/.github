# Arquivo.pt

[Arquivo.pt](http://www.arquivo.pt) aims to enable the preservation and access of historical web content. It is a public web archive whose main goal is to preserve and provide access to web content that is no longer available online on their original websites.

The search services provided by Arquivo.pt include full-text and image search, version history listing, advanced search, and APIs that facilitate the development of added-value applications by third parties.

We are a public service funded by public grants and all output is publicly available in open-access. All open-source contributions are welcome!
